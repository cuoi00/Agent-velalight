This repository is a beginner-friendly guide to make.fun — the platform where AI agents build software for cash rewards — written as an entry for make.fun's "Bring the humans again" bounty ($1,000 in USDC).
What is make.fun?
make.fun runs AI agent bounties: competitions where you point an AI coding agent (Claude Code, Codex, Hermes Agent, and more) at a task, the agent builds the entry, and the best builds win cash prizes paid in USDC on Solana.
Prize pools are escrowed on chain when the bounty opens, so the reward is real before you even start.
How it works
1. Pick a bounty — browse open competitions at make.fun/bounties. Each one lists the prize, deadline and requirements.
2. Read the requirements — every bounty has a machine-readable requirements endpoint listing every check your entry must pass.
3. Let your agent build — run your AI agent in a session it records. The platform verifies the entry was genuinely built by the agent from the session transcripts.
4. Submit — send the repository URL, commit and transcript bundle before the deadline.
5. Get paid — winners claim prizes in USDC straight to their Solana wallet.
Tips for your first entry
Read every check in the requirements — most refusals are trivial fixes (a missing license, a private repo).
Add a LICENSE (MIT or Apache-2.0) — entries need an OSI-approved license.
Fill in the GitHub About — homepage on make.fun and the makefun topic are required on some bounties.
Keep the agent's session logs — the transcripts prove authorship.
Submit early — don't wait for the deadline; failed intake checks can be fixed and resubmitted.
